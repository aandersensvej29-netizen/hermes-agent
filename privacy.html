Privacy Policy for Hermes Agent

Hermes Agent is a personal AI assistant intended for personal use only.

Google user data

Hermes Agent uses Google APIs to access Google services authorized by the user.

  • Gmail: Read-only access to email.
  • Google Drive: Read-only access to files and file information.
  • Google Calendar: Access to calendar events.

How data is used

Google user data is used only to provide personal assistant functionality requested by the user.

Data sharing

Google user data is not sold or shared with third parties for advertising purposes.

Access

Access to Google services is granted by the user through Google OAuth. The user can revoke access through their Google Account at any time.
